# BookMyCelebration
BookMyCelebration is a website where you can book you any type of celebration or event . It provides many facilities such as booking with given packages or customized packages,etc,you find reviews of the past user, you can also share your experience there and many more functionalities. 
The technologies used for this project are HTML,CSS,JavaScript,PHP and Mysql.
Steps to run project : 
1) Install xampp and start apache and mysql services
2) Store the code file in C:\xampp\htdocs\ location.
3) In the browser add url localhost/your project folder name/filename.php
4) You will be able see the website
